## FAQ Section

### Headline
```
Frequently Asked Questions
```

**Q: How accurate is the AI analysis?**
```
A: Our AI achieves 98%+ accuracy compared to manual analysis when validated against TCGA gold standard datasets. We use state-of-the-art language models (Claude 3.5 Sonnet, DeepSeek) that have been specifically trained on biomedical literature. All analyses are reproducible via exported Python code.
```

**Q: What file formats do you support?**
```
A: We support CSV, TSV, and VCF formats. Your file should contain columns for gene names and mutation types at minimum. We auto-detect column formats in most cases.
```

**Q: Is my data secure and private?**
```
A: Yes. All data is encrypted in transit (TLS 1.3) and at rest (AES-256). We are SOC 2 Type II compliant and can sign BAAs for HIPAA-covered entities. Your data is never used to train AI models. Enterprise customers can opt for on-premise deployment.
```

**Q: Can I use this for clinical decision-making?**
```
A: CancerGenomics.AI is currently designed for research use only (RUO). We are working towards CLIA certification for clinical use. For clinical applications, consult with a qualified healthcare provider.
```

**Q: What if I need help interpreting results?**
```
A: Pro and Enterprise plans include interpretation support from our team. We can also connect you with board-certified genetic counselors for clinical interpretation (additional fee).
```

**Q: Do you offer academic discounts?**
```
A: Yes! Academic institutions receive 20% off all paid plans. Contact sales@cancergenomics.ai with your .edu email for verification.
```

**Q: Can I cancel anytime?**
```
A: Absolutely. No long-term contracts. Cancel anytime and keep your analysis history.
```

**Q: What's your refund policy?**

A: 30-day money-back guarantee, no questions asked. If you're not satisfied, we'll refund your first month in full.
